Codex Sitesと同じことを自分で作る場合の比較

2026年7月時点

「プロンプトを打つとWebアプリが公開される」——Codexはこれを認証・データベース・ホスティングを1つにまとめて実現しています。同じ結果を他の方法で作ろうとすると、必要な部品を自分たちで選び、組み合わせる必要があります。ここでは「Codex Sites」「自作①：非Google系」「自作②：Google系」の3パターンで比較します。

構成の違い

Codex Sitesは必要な要素があらかじめ1つになっています。自作する場合も、Google系（Firebase）を使うかどうかで組み立てる部品数が変わります。Firebaseは認証・DB・ホスティングがもともと1つのサービスにまとまっているため、非Google系より部品数が少なくて済みます。

Codex Sites

1つで完結
  • プロンプト入力
  • そのまま公開URL発行
  • 認証・DB・サーバーが最初から一体
  • 設定はほぼ不要

自作① 非Google系

部品を3つ組む
  • 画面・機能を作る：Claude Code
  • 認証・DB：Supabase
  • 公開・ホスティング：Vercel / Netlify

自作② Google系

部品は2つで済む
  • 画面・機能を作る：Claude Code（Geminiでも可）
  • 認証・DB・ホスティング：Firebase（一体）
非Google系は「認証・DB担当」と「公開担当」が別サービスになるため、組む部品が1つ多くなります。Google系はFirebaseが認証・DB・ホスティングを最初からまとめているため、自作の中では最もCodex Sitesに近い構成になります。ただし選べる範囲はどちらもOpenAIの箱の外にあり、自分たちで設計・運用する前提です。

料金の考え方

自作（①非Google系・②Google系のどちらも）は「アプリを使う人の量」に対して課金され、Codexは「アプリを作る人（開発側）の作業量」に対して課金されます。ここが料金設計を考える上で一番重要な違いで、これは自作①②に共通する構造です。

自作①②：利用者数に比例

  • どちらも無料枠あり（Firebase／Supabase＋Vercel）
  • 10人規模の利用ならほぼ無料枠内
  • 超えた分だけ従量課金
  • 利用者が増えるほど費用も増える

Codex：開発作業量に比例

  • 公開後、顧客が何人見ても追加費用は基本なし
  • 費用はサブスク定額＋開発時のAI利用量
  • 実務レベルの目安：月100〜200ドル
  • 利用者数増加はコストに直結しにくい

自作① 非Google系：Supabase + Vercel

サービス無料枠有料プラン

Codex（ChatGPT）

プラン月額内容
Free$0お試し程度。上限が最も厳しい
Plus$20個人利用の標準ライン
Pro$100〜200本格的な開発・毎日利用向け
Business$20〜25／人チーム利用、管理機能つき

10人規模の顧客向けアプリで比較すると、月額の目安は「Google系：ほぼ$0」「非Google系：$20〜（Vercel Pro分）」「Codex：開発の使い方次第で$20〜200」となります。

選び方の目安

Codex Sites：とにかく早く形にしたい

社内向けの検証・試作段階。スピードと手間の少なさを優先するならCodex Sitesが向いています。

自作①非Google系：技術選定の自由度を重視したい

特定のクラウドに縛られたくない、Next.jsなど技術スタックを自分たちで選びたい場合。ただし商用利用にはVercel Proが必要になる点は考慮が必要です。

自作②Google系：コストを抑えつつGoogleと相性よく

顧客がすでにGoogle Workspaceを使っている、または最小コストで本番運用したい場合はFirebaseが有利です。部品数も少なく、自作の中では最もシンプルな構成になります。
